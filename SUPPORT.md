## Privacy when requesting help

Use synthetic clipboard content. Never publish a real database, cached image
directory, settings file, credentials, or a screenshot containing private
information. Remove personal paths, usernames, device names, and unrelated
application content from diagnostic output.

Support is community-maintained and has no guaranteed response time. The
unsigned preview may show Windows reputation warnings; do not disable security
features to bypass them.
