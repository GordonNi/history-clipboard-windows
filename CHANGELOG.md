# Changelog / 更新日志

All notable changes to HistoryClipboard for Windows are documented here.
HistoryClipboard Windows 的重要变更记录在此。

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0-preview.2] - 2026-07-16

### English

- Added local-only text and image clipboard history with search, pinning,
  deletion, clear-all, pause, and 1/3/5-day retention.
- Added tray lifecycle, configurable global shortcut, launch at sign-in,
  single-instance activation, taskbar recovery, and per-monitor-DPI placement.
- Added SQLite/PNG persistence, guarded startup failures, a portable package,
  and a non-administrator per-user installer.
- This prerelease is unsigned. Cross-device synchronization is not included.

### 中文

- 新增仅在本机保存的文字与图片历史，以及搜索、置顶、删除、清空、暂停和
  1/3/5 天保留设置。
- 新增托盘生命周期、可配置全局快捷键、登录启动、单实例唤醒、任务栏恢复和
  每显示器 DPI 定位。
- 新增 SQLite/PNG 持久化、安全启动失败处理、便携包和无需管理员权限的当前用户
  安装器。
- 本预发行版本尚未签名，也不包含跨设备同步。
