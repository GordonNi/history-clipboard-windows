# HistoryClipboard Windows 0.1.0-preview.2 — Unsigned Preview

## English

This is the first public Windows preview of HistoryClipboard.

### Highlights

- Local-only Unicode text and bitmap image history
- Search, pin/unpin, delete, clear-all, pause, and 1/3/5-day retention
- Tray window, configurable global shortcut, launch at sign-in, and single-instance activation
- Per-monitor-DPI placement and Explorer/taskbar restart recovery
- Self-contained portable ZIP and non-administrator per-user installer
- No telemetry, accounts, cloud service, network transport, or synchronization

### Before installing

- This build is **unsigned**. Windows may show Unknown publisher or Microsoft
  Defender SmartScreen. Verify the matching `.sha256` file; do not disable
  Windows security features.
- Exit the running tray application before installing or upgrading.
- The interactive uninstaller defaults to keeping
  `%LOCALAPPDATA%\HistoryClipboard`. Silent uninstall always keeps it.
- Clean Windows 10/11, real mixed-DPI, disposable-profile, and code-signing
  release gates are still pending. This is not a production-ready claim.

Download either the setup plus its checksum or the portable ZIP plus its
checksum from the assets below.

## 中文

这是 HistoryClipboard 的首个公开 Windows 预览版。

### 主要功能

- 仅在本机保存 Unicode 文字和位图图片历史
- 搜索、置顶/取消置顶、删除、清空、暂停和 1/3/5 天保留
- 托盘窗口、可配置全局快捷键、登录启动和单实例唤醒
- 每显示器 DPI 定位以及 Explorer/任务栏重启恢复
- 自包含便携 ZIP 和无需管理员权限的当前用户安装器
- 不包含遥测、账户、云服务、网络传输或跨设备同步

### 安装前须知

- 本版本**尚未签名**。Windows 可能显示“未知发布者”或 Microsoft Defender
  SmartScreen。请核对对应 `.sha256` 文件，不要关闭 Windows 安全功能。
- 安装或升级前请先从托盘退出正在运行的应用。
- 交互式卸载默认保留 `%LOCALAPPDATA%\HistoryClipboard`；静默卸载始终保留。
- 干净 Windows 10/11、真实混合 DPI、可丢弃账户和代码签名门禁仍未完成。本版本
  不代表已经达到正式生产发布标准。
